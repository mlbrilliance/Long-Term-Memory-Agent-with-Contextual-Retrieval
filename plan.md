# Plan: Long-Term Memory Agent with Contextual Retrieval
## Project Synapse Initiative

**Goal:** Develop a Python-based Langchain Agent (`:LongTermMemoryAgent`) utilizing Anthropic's `:ContextualRetrieval` methodology for persistent, evolving long-term memory (LTM) management within the `:WindSurfIDE` `:EnvironmentContext`, adhering to best coding practices and TDD.

**Core Principles (Mandatory Adherence):**
*   **Orchestration:** All tasks managed by `🌌 Nexus Core Orchestrator` (Ω).
*   **Micro-Tasking:** Plan broken into smallest logical units (`μT`).
*   **SAPPO Integration ([SAPPO]):** All communication, planning, and components framed using the LTM Agent Ontology (`ltm_agent_ontology.ttl`) terms.
*   **Rapid Iteration Cycle (⚡️🔁):** Enforce immediate `Code -> Targeted Test -> Fix/Refine` loop for core functionality. **TDD Focus**: Tests (`🎯🧪`) defined *before* or *concurrently* with implementation.
*   **Targeted Testing Strategy (🎯🧪):** `@QuantumVerifier` MUST implement BOTH `🎯🧪<core>` (using `:TDDAnchor`s) AND `🎯🧪<ctx>` (testing `:ContextualIntegrationPoint`s based on Ω context) immediately after code completion.
*   **Strategic RDD/MCP (🧠):** Specialists use Perplexity MCP **via the `perplexity-research-service` defined in `mcp.json`** judiciously as per Universal Instructions & Tiered Role guidance. Usage MUST be logged in 📤 summaries.
*   **Modularity (<500L):** Strict adherence to `< 500 lines` per file/unit/doc section.
*   **Security (🚫🔑):** No hardcoded secrets. Validate inputs. Security review by `@AegisSentinel` where specified. Configuration via environment variables (`.env`) is mandatory.
*   **Technology:** `:Python` (>=3.10 Recommended), `:Langchain`, chosen `:VectorStore` (e.g., `:ChromaDB`), chosen `:EmbeddingModel`, `:ClaudeAPI` (or equivalent LLM API), Optional `:CohereReranker`. Environment Manager: `uv` (preferred) or `venv`. Formatter: `black`. Linter: `ruff`. Test Runner: `pytest`.
*   **Testing:** `:Pytest` framework mandatory for 🎯🧪. Test files colocated in `tests/` mirroring `src/` structure. **Test early, test often.**
*   **Responsible Scaling (:ResponsibleScalingPolicyAspect):** Monitor agent's learning autonomy. Flag significant self-improvement to Ω.
